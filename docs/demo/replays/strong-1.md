Subject: This Morning's Outage at All Three Offices — Resolved

Dana,

This morning, all three Harbor Dental locations lost access to Dentrix for about 90 minutes starting around 8:47 AM. The cause was a network security certificate on your main office's firewall that expired, which cut off the connection between Midtown, Riverside, and the server. All three locations were back up and confirmed working by 10:25 AM.

No patient data was affected. The dental server itself was never down or at risk — the offices simply couldn't reach it during the outage.

Going forward, we're adding monitoring that will alert us 30 days before any certificate like this is set to expire, so we catch it well before it can cause a problem. That will be in place by Friday.

Sorry for the disruption to your morning — I know a full waiting room makes this worse. Let me know if you have questions.
